# Codename Engine compatibility

Psych Importer 1.0.1 uses Codename Engine 1.0.1 as its reference target.

| Codename version | Validation |
|---|---|
| 1.0.1 | File contracts checked against the local engine source, automated format and regression checks, and representative runs in the installed engine. |
| 1.0.0, 0.x releases and forks | Not fully validated for this release. Reading part of the format does not establish support for every event, script or atlas. |

## File contracts

Checks cover native charts with `strumLines`, difficulty metadata, difficulty-specific Inst and Voices, Freeplay lists, character and stage XML, Sparrow and Packer atlases, supported Animate assets, and icon health states.

Animated icons use `images/icons/<key>/icon.png`, `icon.xml` and `data.xml`. Static icons use `images/icons/<key>.png`.

Character and stage keys declared in a chart are retained when another loaded resource is assigned to them. Difficulties sharing a key must export the same resource behind it. Conflicting assignments block the package.

## Events and behavior

Psych events without an equivalent are preserved as inactive `Unknown` entries, with their original names and parameters available for review. A matching native event name does not activate them. Native events generated by the reader, such as camera movement from chart sections, remain active.

Supported modchart conversion is separate from general script porting. Unsupported operations and custom mechanics need manual review. The general script-connection sources in the Developer WIP folder are not connected to the application.

## Validation performed for 1.0.1

- Automated regression checks for parsing, export, audio variants, atlases, partial plans, source isolation and transaction metadata.
- Eighteen export scenarios and 32 resulting packages from three local Psych mods checked for structure. Charts-only output is explicitly checked as a partial resource that requires external audio.
- ZIP local headers checked using Codename 1.0.1's reading rules.
- Ballistic/erect and 4hot/hard run in Codename Engine 1.0.1 for ten seconds each, with the exported characters and stages visible and playback/pause controls verified.

A structure check validates files and references. An engine run validates the song, difficulty and segment exercised. These checks do not certify every mod, every scripted mechanic or every engine build carrying the same version label.

## Defensive limits

The import/export path limits strumlines to 256, keys to 32 per line, chart times to 24 hours and Animate timelines to 50,000 frames with a composition work budget. Characters support up to eight Animate pages. Additional image, sustain geometry, file-count and output-size limits prevent unbounded work.

Resources exceeding a limit are reported for review. The tool does not silently publish them as valid conversions.

Psych Engine version coverage will be documented separately.
