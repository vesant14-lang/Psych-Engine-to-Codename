# Reporting stability and output-integrity issues

Report reproducible crashes, writes outside the selected destination, lost destination data or unexpectedly active converted behavior through the reporting channels available in this repository. Use private reporting when available for details that should not be public.

Include the importer version, Windows version, target engine version, exact actions, selected output mode and relevant report/log lines. Identify whether the problem occurs during discovery, preview, plan review, writing or loading the exported mod in Codename.

Keep personal paths, private assets and files without redistribution permission out of public attachments. A synthetic sample or a minimal permitted fixture is enough when it reproduces the problem.

The tool's write checks and conversion reports are safeguards, not a claim that every file format or custom mod behavior has been verified. The current validation scope is documented in [CODENAME_COMPATIBILITY.md](CODENAME_COMPATIBILITY.md).
